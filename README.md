# Second Brain Frontend

A beautiful, responsive, and highly interactive frontend for the Second Brain personal knowledge management application. Built to deliver a premium user experience with fluid animations, dynamic dark mode, and a highly polished UI.

## ✨ Key Features
- **Modern UI/UX**: Glassmorphism, smooth Framer Motion animations, and beautiful typography.
- **Dynamic Themes**: Full support for system, light, and dark modes with seamless color swapping.
- **Content Management**: Interactive cards for notes, videos, tweets, and documents with auto-extracted metadata.
- **Responsive Design**: Flawless experience across desktop, tablet, and mobile with a collapsible sidebar and optimized mobile layouts.
- **User Onboarding**: Animated, multi-step onboarding flow for new users.

## 🛠️ Tech Stack
- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Components**: Radix UI (accessible, unstyled primitives)
- **Animations**: Framer Motion
- **Icons**: Lucide React & Phosphor Icons
- **Data Fetching**: Axios

## 🚀 Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Environment Setup**
   Copy the example environment file:
   ```bash
   cp example.env .env.local
   ```
   *Note: By default, the API URL will automatically map to your current hostname.*

3. **Run the Development Server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.
